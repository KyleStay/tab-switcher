App Review

What works well

The extension has a strong core shape: a fast popup, fuzzy title and URL ranking, MRU ordering, recently closed restore, command-based cycling, and a small options page. The pure logic lives in src/core/, which keeps ranking and MRU behavior easy to test.

User experience strengths

The popup supports reliable keyboard navigation, mouse selection, highlighted matches, badges for context, duplicate-title numbering, copy URL, close tab, density control, and first-run shortcut guidance. It feels appropriately close to an editor quick-open palette.

Important gap

The native/ folder describes a macOS Ctrl+Tab helper, but the current extension manifest does not request nativeMessaging, and src/background.js does not connect to com.tab_switcher.native. Treat the native helper as unfinished or experimental until that integration is added.

Manual QA still needed

The automated Node tests cover core ranking, MRU behavior, shortcut mapping, settings defaults, and popup layout contracts. Browser smoke testing is still needed after extension UI or manifest changes: reload the unpacked extension, open the popup, verify shortcuts, switch tabs, restore a closed tab, and save options.

Getting Started

  1. Open Chrome and go to chrome://extensions.
  2. Turn on Developer mode.
  3. Choose Load unpacked.
  4. Select the project folder: /Users/kyle/Documents/Tab Switcher.
  5. Pin Tab Switcher from Chrome's extensions menu if you want mouse access to the popup.
  6. Open chrome://extensions/shortcuts and confirm or assign the shortcuts.

First thing to check: Chrome may leave suggested shortcuts unassigned if they conflict with browser or system shortcuts. The extension will show shortcut guidance on first run when the popup shortcut is missing.

Daily Use

Open the Switcher

Use the assigned open-switcher shortcut or click the extension icon. The popup lists open tabs in most-recently-used order.

Search Tabs

Type part of a title or URL. Short queries use fuzzy matching, so initials and partial words work well. Long queries use exact matching for more predictable results.

Choose a Result

Use Tab, Shift+Tab, arrow keys, page keys, Command/Ctrl editor-style movement chords, or the mouse to select a row. Press Enter to switch to an open tab or restore a closed tab.

Understand Rows

Rows show the title, simplified URL, favicon, action, and badges such as current tab, recently closed, pinned, audio, muted, incognito, duplicate number, or window ID.

Shortcuts

Action Default shortcut Notes
Open switcher Command+E on macOS, Ctrl+E elsewhere, plus Alt+E on Windows Configured by Chrome as extension shortcuts. Use the movement shortcuts below after the popup opens.
Cycle to older MRU tab Option+Q on macOS, Alt+Q elsewhere Works outside the popup and moves through tabs from newer to older recent use.
Cycle to newer MRU tab Option+Shift+Q on macOS, Alt+Shift+Q elsewhere Works outside the popup and moves backward through the same MRU session.
Move popup selection Tab, Shift+Tab, Arrow Down, Arrow Up, Ctrl+N, Ctrl+P, Ctrl+J, Ctrl+K Works inside the focused popup. On macOS, Command also works for the letter chords.
Jump through results Page Down, Page Up, Home, End Useful when many results are visible.
Activate selected Enter Switches to an open tab or restores a recently closed tab.
Close selected open tab Command+W on macOS, Ctrl+W elsewhere Does nothing for recently closed rows.
Copy selected URL Command+C on macOS, Ctrl+C elsewhere Copies the selected row's URL to the clipboard.
Clear or close Esc Clears the search box first. If it is already empty, closes the popup.

About Ctrl+Tab: Chrome normally owns browser tab-switching shortcuts before extension popup JavaScript can see them. Tab Switcher uses configurable extension shortcuts instead of promising control over reserved browser shortcuts.

Settings

Open settings from the popup's Options button, the extension details page, or Chrome's extension menu.

Setting What it does
Current window only Limits popup results and MRU cycling to the active Chrome window.
Include recently closed tabs Adds restorable closed tabs to the result list using Chrome sessions.
Restore previous query Restores the last non-empty popup search during the same browser session.
Theme Uses system, dark, or light styling for the popup.
Density Chooses compact or comfy result row spacing.
Maximum results Controls how many ranked results the popup displays. The options UI allows values from 20 to 300.
Automation expires after Stores a duration in minutes, from 1 to 1440, for automation consumers to read from extension settings.
Test keepalive prompt automation Activates a test keepalive prompt automation flag in settings so the app can detect and exercise that path.

Recently Closed Tabs

When Include recently closed tabs is enabled, Tab Switcher asks Chrome for recent tab sessions and adds matching closed tabs below the open-tab results. Closed tabs are labeled Recently closed and use Restore as their action.

Press Enter on a closed-tab result to restore it. The extension relies on Chrome's session restore data, so availability depends on what Chrome still has in its recently closed list.

Native Helper

The repository includes a macOS native helper intended to intercept Ctrl+Tab and Ctrl+Shift+Tab, then communicate with the extension through Chrome Native Messaging.

Current status: the helper files exist, but the extension is not currently wired to them. The manifest lacks the nativeMessaging permission, and the background service worker does not open a native messaging port. Use the standard Chrome extension shortcuts until native integration is completed.

native/README.md documents the prototype host files for future development, not a supported user setup.

Troubleshooting

The shortcut does not open the popup

Go to chrome://extensions/shortcuts and make sure Tab Switcher has an assigned shortcut. Chrome may reject or reserve some combinations.

Results look stale

Reload the unpacked extension from chrome://extensions. The service worker refreshes tab state on install, startup, and tab/window events.

Recently closed tabs are missing

Confirm that Include recently closed tabs is enabled. Chrome may also limit what it returns through its sessions API.

Options do not save

Check the options page status line. Settings are saved to chrome.storage.local; reloading the extension can help after manifest or source changes.

Privacy

Tab Switcher uses the Chrome tabs, storage, and sessions permissions. It reads tab titles, URLs, favicons, window IDs, and recently closed tab sessions so it can rank, display, switch, close, and restore tabs.

Settings and MRU tab state are stored locally through chrome.storage.local. There is no network code in the extension source reviewed for this guide.

Developer Notes

This project intentionally has no build step. Core logic lives in src/core/, Chrome API integration lives in src/background.js, and the popup/options pages use plain ES modules.

Run tests with:

npm test

Verification for this repository should always include npm test. Browser-facing changes also need an unpacked-extension reload and smoke test in Chrome.
