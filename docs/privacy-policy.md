# Tab Switcher Privacy Policy

Tab Switcher uses Chrome’s tab and session information to find, switch to, close, and restore tabs. The extension reads tab titles, URLs, window and tab identifiers, and recent-use information. It uses Chrome’s locally cached site icons when available. Recently closed tabs come from Chrome’s session list.

Tab Switcher processes this information on your device. It uses Chrome’s local extension storage to keep your settings and the sites you choose to open in the popup. If you enable **Restore previous query**, Chrome’s extension session storage keeps your most recent search until the browser session ends. Tab Switcher skips saving searches in incognito and disables query storage whenever private tab support is enabled. It does not save a separate record of tab titles, URLs, or browsing history to disk.

Private tab support requires you to allow the extension in Incognito in Chrome and enable private tabs in Tab Switcher Settings. You can choose which private details the switcher shows. Copying a tab URL places it on your device’s clipboard when you use the copy shortcut.

Tab Switcher has no analytics or advertising and sends no user data to the developer or to third parties. Switching or restoring a tab may cause Chrome to load that site normally. Removing the extension clears its Chrome extension storage.

Tab Switcher uses information from Chrome APIs only to provide its tab-switching features and complies with the Chrome Web Store User Data Policy, including its Limited Use requirements.
